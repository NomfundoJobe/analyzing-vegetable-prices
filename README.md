# Project Title: Analysis of Seasonal Price Variations in Vegetable

# Link to Trello board 
https://trello.com/b/1a0tSjkI/analyzingveggies

Overview

This project explores seasonal price variations in vegetables using data analysis techniques. The goal is to uncover trends and patterns that affect vegetable prices across different time periods. By identifying these trends, stakeholders such as farmers, retailers, and policymakers can make informed decisions.
Author

This project was completed solely by Nomfundo.
Key Files

    veggies.ipynb:
    A Jupyter Notebook containing:
        Data preprocessing and cleaning.
        Exploratory Data Analysis (EDA) with visualizations.
        Key insights into seasonal price trends.

Goals and Insights

    Project Goals:
        Investigate how vegetable prices change seasonally.
        Provide insights into which vegetables are most affected by seasonality.
        Suggest data-driven strategies to address price volatility.

    Key Insights:
        Seasonal patterns in pricing.
        Vegetables with the most stable prices.
        Factors contributing to price spikes.

Technologies Used

    Python:
        Libraries: Pandas, NumPy, Matplotlib, Seaborn.
    Jupyter Notebook for interactive analysis.

How to Use

    Open the veggies.ipynb notebook in a Jupyter environment.
    Follow the step-by-step analysis to understand the dataset and insights.
    Modify or extend the code for additional analysis or visualization.
